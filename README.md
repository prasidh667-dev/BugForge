# BugForge – Issue Tracker

Open `index.html` in any modern browser. No install or build step needed.

## Demo logins
- Admin: admin@demo.com / admin123
- Manager: manager@demo.com / manager123
- Developer: dev@demo.com / dev123

## Notes
- Data is saved in your browser (localStorage), so it stays on your device only.
- Roles: Admin and Manager can create projects and manage members; Developers can edit or move only issues they reported or are assigned to.
- Fonts load from Google Fonts when online; the app falls back to system fonts offline.
